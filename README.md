# My Prompt Writer

A step-by-step story writing program for 4th graders who need help brainstorming and writing sentences. It goes with the printable **My PROMPT Book**.

## Steps
1. **Word Power** – 6 vocabulary words with meanings, examples, and "use it in a sentence"
2. **Sentence Builder** – Who / Did what / Where / When / Why, with a "Stretch it!" sentence
3. **Pick a Prompt** – 4 prompts with starter sentences and a quick write
4. **Word Bank Story** – tap words to add them to a story
5. **Fill-in Story** – "The Day the Lunchroom Went Wild"
6. **Brainstorm** – a story web
7. **Plan It** – First, Next, Then, Finally
8. **Write My Story** – Beginning, Middle, End, with the brainstorm and plan beside the writing
9. **Check and Shine** – self-check with some automatic checks, plus a star and a wish

At the end, the student can read the finished story, copy it, or start a new one.

## How to use
Open `index.html` in a web browser. Work saves in that browser by itself.

Note: the "Say it" (talk-to-type) and download buttons only work inside Claude. Outside Claude, the read-aloud button uses the browser's built-in voice if it has one.
